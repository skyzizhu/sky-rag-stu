# 入库编排（Ingest Pipeline）

对应需求：FR-INGEST-001 ~ 006。完整规则与验收见「需求文档 → RAG 编排需求与验收」。

入库编排解决"知识怎么存进去、存得对、存得省"：七节点顺序执行（增量判断 → 解析 → 元数据 → 清洗 → 切片 → 向量化 → 索引），核心设计约束：

1. **输入归一化**：7 类输入源（6 种文件格式 + 网页 URL）统一转为带元数据的纯文本，网页去噪、表格空格归一化、Front Matter 损坏降级
2. **增量优先**：内容指纹未变化直接跳过（省 LLM 标签与向量化）；显式路径默认强制重入库，网页入库走指纹跳过
3. **版本留痕**：内容变化自动升版本，旧版本卡片转 expired 留作历史
4. **一致性兜底**：台账在向量写入成功后落盘、原子写盘、损坏告警；删除文件同步清向量
