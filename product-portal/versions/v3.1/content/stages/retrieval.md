# 检索编排（Retrieval Pipeline）

对应需求：FR-RTV-001 ~ 005。完整规则与验收见「需求文档 → RAG 编排需求与验收」。

检索编排解决"该找的找得全、找得准"：Query 理解 → 向量化 → 过滤 → 双路检索 → RRF 融合 → Rerank → 合并去重。核心设计约束：

1. **Query 理解**：一次 LLM 调用完成改写、关键词、过滤推断（宁少勿错）与计数/列举意图判定
2. **双路互补**：向量通道管语义，BM25 关键词通道管专有名词/编号/缩写，RRF 融合排名
3. **计数扩容**：识别计数/列举意图时召回翻倍、上下文翻倍、单文档上限放开（三旋钮同拧）
4. **Rerank 只排序不过滤**：LLM 打分有随机性，仅用于选取 Top K
