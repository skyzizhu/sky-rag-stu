# 非功能需求

| 维度 | 要求（真实实现口径） |
|---|---|
| 性能 | 同 URL 重复网页录入 ≤1s（增量跳过）；状态灯检查超时 3s、缓存 30s；流式回答首字秒级；入库进度分步反馈 |
| 安全 | API Key 仅存 .env 不进 git/界面/日志；知识卡片与网页内容渲染前 HTML 转义（防存储型 XSS）；session_id 正则校验防路径穿越；网页抓取 5MB 上限与 Front Matter 注入防护 |
| 兼容 | 桌面 Chrome / Safari（Streamlit 支持的版本）；不适配移动端 |
| 可用性 | 全部错误为可读提示（中文/跟随界面语言）+ 排查指引；会话/台账/设置原子写盘，崩溃不丢数据 |
| 隐私 | 知识内容与向量全部本机（Qdrant 本机、embedding 本机 Ollama）；仅 LLM 生成与自动标签调用云端 API |
| 无障碍 | 状态以 emoji + 文字双通道表达；对比度按主题变量体系 |
| 一致性 | 多标签页写设置以原子写防损坏（接受后写覆盖先写）；入库并发串行化加锁 |
